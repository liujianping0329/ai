3. DatabaseTools

@Component
public class DatabaseTools {

    private final SchemaService schemaService;

    public DatabaseTools(SchemaService schemaService) {
        this.schemaService = schemaService;
    }

    @Tool(description = "根据数据库表名读取真实表结构，不允许自行猜测字段")
    public TableSchema getTableSchema(
        @ToolParam(description = "数据库表名")
        String tableName
    ) {
        return schemaService.getTableSchema(tableName);
    }
}
注解作用
@Component让 Spring 创建 Bean，可以注入到 Service
@Tool告诉 Spring AI 这个方法可以给模型调用

如果漏掉 @Component，会出现类似：

required a bean of type 'com.next.ai.tool.DatabaseTools'
that could not be found

5. 为什么注释很重要

字段注释实际上是在给 AI 补“业务语义”。

created_at → 消费创建时间
amount     → 消费金额
category   → 消费分类

尤其数据库字段是缩写时更有帮助：

amt     → 消费金额
biz_dt  → 业务发生日期
cate_id → 消费分类ID

6. PostgreSQL 读取字段和注释的 SQL

SELECT
    a.attname AS "columnName",
    pg_catalog.format_type(a.atttypid, a.atttypmod) AS "dataType",
    CASE
        WHEN a.attnotnull THEN 'NO'
        ELSE 'YES'
    END AS "isNullable",
    pg_catalog.col_description(a.attrelid, a.attnum) AS "comment"
FROM pg_catalog.pg_attribute a
JOIN pg_catalog.pg_class c
    ON a.attrelid = c.oid
JOIN pg_catalog.pg_namespace n
    ON c.relnamespace = n.oid
WHERE n.nspname = 'public'
  AND c.relname = #{tableName}
  AND a.attnum > 0
  AND NOT a.attisdropped
ORDER BY a.attnum

7. SQL 各部分含义

对象 / 表达式含义
pg_attribute字段相关系统信息
pg_class表、视图、索引等数据库对象
pg_namespaceSchema，例如 public
a.attname字段名
format_type(...)把 PostgreSQL 内部类型转换成人能读懂的类型
a.attnotnull字段是否 NOT NULL
col_description(...)字段注释
c.relname = #{tableName}指定要查哪张表
a.attnum > 0排除 PostgreSQL 系统列
NOT a.attisdropped排除已经删除的字段

8. MyBatis Mapper

@Mapper
public interface SchemaMapper {

    @Select("""
        SELECT
            a.attname AS "columnName",
            pg_catalog.format_type(a.atttypid, a.atttypmod) AS "dataType",
            CASE WHEN a.attnotnull THEN 'NO' ELSE 'YES' END AS "isNullable",
            pg_catalog.col_description(a.attrelid, a.attnum) AS "comment"
        FROM pg_catalog.pg_attribute a
        JOIN pg_catalog.pg_class c ON a.attrelid = c.oid
        JOIN pg_catalog.pg_namespace n ON c.relnamespace = n.oid
        WHERE n.nspname = 'public'
          AND c.relname = #{tableName}
          AND a.attnum > 0
          AND NOT a.attisdropped
        ORDER BY a.attnum
        """)
    List<ColumnMeta> getColumns(
        @Param("tableName") String tableName
    );
}

#{tableName} 是 MyBatis 参数绑定，不是直接把字符串拼进 SQL。

10. SchemaService

除了查询 Schema，还应该做白名单检查：

@Service
public class SchemaService {

    private final SchemaMapper schemaMapper;
    private final TableCatalogService tableCatalogService;

    public SchemaService(
        SchemaMapper schemaMapper,
        TableCatalogService tableCatalogService
    ) {
        this.schemaMapper = schemaMapper;
        this.tableCatalogService = tableCatalogService;
    }

    public TableSchema getTableSchema(String tableName) {

        boolean allowed = tableCatalogService.getTables()
            .stream()
            .anyMatch(t -> t.name().equals(tableName));

        if (!allowed) {
            throw new IllegalArgumentException("不允许读取该表：" + tableName);
        }

        var columns = schemaMapper.getColumns(tableName);
        return new TableSchema(tableName, null, columns);
    }
}

因此 table-catalog.json 不只是给 AI 找表，也可以同时充当允许查询表的白名单。

11. 一个 Service 串起第一层和第二层

学习阶段先放在一个 Service 里最直观：

@Service
public class SchemaAiService {

    private final ChatClient chatClient;
    private final TableCatalogService tableCatalogService;
    private final DatabaseTools databaseTools;

    public SchemaAiService(
        ChatClient.Builder builder,
        TableCatalogService tableCatalogService,
        DatabaseTools databaseTools
    ) {
        this.chatClient = builder.build();
        this.tableCatalogService = tableCatalogService;
        this.databaseTools = databaseTools;
    }

    public String getSchema(String question) {

        String systemPrompt = """
            你负责根据用户问题选择数据库表，并读取对应表结构。

            可用业务表：
            %s

            规则：
            - 只能选择上述表
            - 不能创造表名
            - 无法判断时返回 UNKNOWN
            - 确定表以后，必须调用 getTableSchema 工具读取真实表结构
            - 不允许自行猜测字段名
            """.formatted(tableCatalogService.getTables());

        return chatClient.prompt()
            .system(systemPrompt)
            .user(question)
            .tools(databaseTools)
            .call()
            .content();
    }
}

12. 最关键的两句

.system(systemPrompt)

这是 Context：把业务表目录和规则给 AI。

.tools(databaseTools)

这是 Tool：把 getTableSchema() 这种能力交给 AI。

15. 为什么第二层暂时返回 String

第一层单纯选表时，可以使用：

.entity(TableSelection.class)

第二层加入 Tool 后，为了先观察整个工具调用过程，当前用：

.call()
.content()

以后第三层需要继续给程序处理时，再定义 SchemaResult、QueryPlan 等结构化对象。

17. 第二层复习重点

  1. 第一层通过 Context 选表。
  2. 第二层通过 @Tool 获取真实 Schema。
  3. AI 不允许猜字段。
  4. 字段注释要尽量返回，帮助 AI 理解业务语义。
  5. table-catalog.json 可以同时作为表白名单。
  6. Tool → Service → MyBatis Mapper → PostgreSQL。
  7. 当前重点是把 Schema Tool 链路跑稳定。
当前完整链路： Context 选表 → Tool 读 Schema → MyBatis 查 pg_catalog → AI 理解真实字段。

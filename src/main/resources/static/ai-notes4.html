最后也从：

因为 QueryPlan 不再是最终结果，而是 AI 内部进入真实查询前的中间计划。

3. Prompt 开始要求完整执行

执行步骤：
1. 根据用户问题选择最合适的业务表
2. 必须先调用 getTableSchema 获取真实字段结构
3. 根据真实字段生成查询计划
4. 必须调用 queryData 工具执行查询
5. 只能根据 queryData 返回的真实数据回答用户
6. 不允许自行猜测数据库中不存在的数据

4. DatabaseTools 新增 queryData

@Tool(description = "根据已经生成并校验的查询计划查询业务数据")
public List<Map<String, Object>> queryData(QueryPlan plan) {
    return queryDataService.execute(plan);
}

现在 Tool 分成两类：

  • getTableSchema()：读取真实数据库元数据
  • queryData()：根据 QueryPlan 查询真实业务数据

5. 新增 QueryDataService

@Service
public class QueryDataService {

    private final QueryDataMapper queryDataMapper;

    public QueryDataService(QueryDataMapper queryDataMapper) {
        this.queryDataMapper = queryDataMapper;
    }

    public List<Map<String, Object>> execute(QueryPlan plan) {
        return queryDataMapper.query(plan);
    }
}

职责：接收 QueryPlan → 调 Mapper → 返回动态查询结果。

6. 为什么返回 List<Map<String,Object>>

AI 查询字段是动态的，因此固定 DTO 不合适：

这次：
id, title, amount

下次：
category, created_at

所以：

List<Map<String, Object>>

很适合动态结果集。

7. QueryDataMapper

@Mapper
public interface QueryDataMapper {
    List<Map<String, Object>> query(QueryPlan plan);
}

Mapper 接口只保留方法定义，真正动态 SQL 放到 XML。

9. ${} 和 #{} 的区别

写法含义注意
${table}直接字符串替换必须经过白名单
${field}动态字段名必须经过白名单
#{value1}参数绑定相对安全
#{limit}参数绑定相对安全
MyBatis 可以完成 AI 动态查询，但动态表名和字段名无法通过 #{} 参数化，所以 Validator 是硬安全边界。

10. mapper-locations 配置

mybatis.mapper-locations=classpath*:mapper/**/*.xml

因为 XML 放在独立的 resources/mapper/ 下，显式配置更清楚，也更符合常见工程写法。

11. Invalid bound statement 的含义

Invalid bound statement (not found):
com.next.ai.mapper.QueryDataMapper.query

表示 Mapper 接口已经找到，但对应 XML statement 没有被加载或绑定成功。

需要确认：

Java Mapper：
com.next.ai.mapper.QueryDataMapper

XML namespace：
com.next.ai.mapper.QueryDataMapper

Java 方法：
query()

XML：
<select id="query">

16. 当前仍需补强：Validator

现在 queryData() 已经真正执行动态 SQL，因此后续应确保：

@Tool
public List<Map<String,Object>> queryData(QueryPlan plan) {

    queryPlanValidator.validate(plan);

    return queryDataService.execute(plan);
}

至少验证：

  • table 在允许列表
  • select / filter / orderBy 字段真实存在
  • operator 在允许列表
  • direction 只能 ASC / DESC
  • limit ≤ 100

17. Prompt 和 Validator 的区别

Prompt
→ 软约束
→ 告诉 AI 应该怎么做

Validator
→ 硬约束
→ 不合法就绝对不能执行

MyBatis
→ 只执行已经通过校验的 QueryPlan

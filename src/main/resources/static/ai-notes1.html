2026-08-25 Spring AI 数据库查询原型学习总结

用于项目内直接访问和日后复习

1. 整体目标

目标：用户输入自然语言，例如：

查询中午时段的消费记录
用户问题
   ↓
① 找到应该查询的业务表
   ↓
② Tool 读取该表真实结构
   ↓
③ AI 根据字段结构生成 QueryPlan
   ↓
④ Java 校验 QueryPlan
   ↓
⑤ jOOQ DSL 构造 SQL
   ↓
⑥ 查询数据库
   ↓
⑦ AI 整理结果

职责划分：

  • AI：理解用户意图
  • Java：限制和校验
  • MyBatis：读取数据库元数据 / DDL 信息
  • jOOQ：动态构造查询

2. 第一阶段：找表

快速原型阶段，把允许 AI 使用的业务表放在：

src/main/resources/ai/table-catalog.json

这一层只负责告诉 AI：有哪些表，以及每张表是做什么的。

3. TableMeta 与 record

public record TableMeta(
    String name,
    String description,
    List<String> keywords
) {
}

record 适合 DTO / 数据载体，会自动生成构造方法、equals()、hashCode()、toString()，字段通过 table.name() 访问。

4. TableCatalogService

Spring Boot 4 默认使用 Jackson 3：

package com.next.ai.service;

import com.next.ai.vo.TableMeta;
import java.io.IOException;
import java.util.List;
import org.springframework.core.io.ClassPathResource;
import org.springframework.stereotype.Service;
import tools.jackson.core.type.TypeReference;
import tools.jackson.databind.json.JsonMapper;

@Service
public class TableCatalogService {

    private final List<TableMeta> tables;

    public TableCatalogService(JsonMapper jsonMapper) throws IOException {

        var resource =
            new ClassPathResource("ai/table-catalog.json");

        this.tables = jsonMapper.readValue(
            resource.getInputStream(),
            new TypeReference<List<TableMeta>>() {}
        );
    }

    public List<TableMeta> getTables() {
        return tables;
    }
}

如果继续注入旧的 com.fasterxml.jackson.databind.ObjectMapper，Spring Boot 4 可能找不到对应 Bean。

6. 当前“找表”阶段不需要 Tool

核心是把表目录放进 System Prompt：

String systemPrompt = """
    你负责根据用户问题选择数据库表。

    可用业务表：
    %s

    规则：
    - 只能选择上述表
    - 不能创造表名
    - 无法判断时返回 UNKNOWN
    """.formatted(
        tableCatalogService.getTables()
    );

%s 可以直接接受对象。formatted() 会使用对象字符串表示；record 自动生成了 toString()。

7. ChatClient 调用链

chatClient.prompt()
    .system(systemPrompt)
    .user(question)
    .call()
    .entity(TableSelection.class);
  • prompt()：开始构建一次 AI 请求。
  • system(...)：提供角色、规则和 Context。
  • user(...)：放入用户实际问题。
  • call()：真正调用 LLM。
  • entity(...)：把结果转成 Java 对象。

8. TableSelection

public record TableSelection(
    String tableName,
    String reason
) {
}

AI 预期返回：

{
  "tableName": "cost",
  "reason": "用户查询的是消费记录"
}

Java 中直接：

result.tableName();
result.reason();

9. 测试 Controller

@RestController
@RequestMapping("/api/ai")
public class AiController {

    private final TableSelectionService tableSelectionService;

    public AiController(TableSelectionService tableSelectionService) {
        this.tableSelectionService = tableSelectionService;
    }

    @Operation(
        summary = "根据用户问题选择数据库表",
        description = "根据自然语言问题，从业务表目录中选择最合适的数据库表"
    )
    @GetMapping("/table")
    public TableSelection findTable(
        @Parameter(
            description = "用户自然语言查询",
            example = "查询中午时段的消费记录"
        )
        @RequestParam(
            name = "q",
            defaultValue = "查询中午时段的消费记录"
        )
        String q
    ) {
        return tableSelectionService.selectTable(q);
    }
}

11. MyBatis 和 jOOQ 的职责

MyBatis

适合固定、受控 SQL，例如：

SELECT
    column_name,
    data_type,
    is_nullable
FROM information_schema.columns
WHERE table_schema = 'public'
  AND table_name = #{tableName}
ORDER BY ordinal_position;

jOOQ

以后根据 QueryPlan 动态构造 SELECT / WHERE / ORDER BY / JOIN / LIMIT。

不推荐直接暴露：

@Tool
executeSql(String sql)

更推荐：

AI
 ↓
QueryPlan
 ↓
Java Validator
 ↓
jOOQ DSL
 ↓
SQL

12. 当前学习顺序

  1. 读取 table-catalog.json
  2. 通过 System Prompt 把表目录作为 Context 给 AI
  3. 让 AI 正确选表
  4. 用 TableSelection 接收结构化结果
  5. 通过 Controller + Swagger 单独测试
  6. 再写 @Tool getTableSchema()
  7. 再接 MyBatis
  8. 最后做 QueryPlan + jOOQ
